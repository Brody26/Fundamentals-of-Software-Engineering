Пояснения к задачам

A4:
переменная diff считает разность введённых чисел, после в переменной k находится остаток при деление diff на 1000.Если при деление остаток отрицательный, значит наибольшее число это b, если остаток положительный то a.

А6:
Строка N%= 86400 означает если N будет больше 86400(количество секунд в сутках) секунд вернёт остаток при деление на это число, а если N < 86400, то оно останется прежним.
